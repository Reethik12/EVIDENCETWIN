## 1. Executive Summary & Problem Statement

Law enforcement, narcotics control bureaus, and border security forces globally utilize physical colorimetric test kits (e.g., Marquis, Scott, Duquenois-Levine) for rapid roadside and field drug screening. However, field operations face critical structural limitations:

1. **Ambient Lighting Drift & Subjective Visual Interpretation:** Ambient lighting (sodium lamps, sunset, fluorescent tubes) changes color perception, causing false reads.
2. **"Black Box" AI Skepticism:** Standard AI classifiers simply output "POSITIVE" without explaining optical quality, fiducial alignment, or color spectrum shifts.
3. **Chain-of-Custody & Evidence Integrity Challenges:** Photos taken on personal phones lack tamper-evident cryptographic linkage between raw pixels, calibration matrices, and classification outcomes.
4. **Boundary Instability:** Officers have no way of knowing if a subtle camera shake or slight exposure variation would have changed the presumptive read.

## 2. The Key Innovation: "The EvidenceTwin"

Rather than merely outputting a binary classification, **EvidenceTwin** constructs an immutable digital twin of the entire evidence-processing journey:

```
CAPTURE 
   ↓ 
REFERENCE CARD DETECTED (6-Patch Fiducials)
   ↓ 
IMAGE QUALITY AUDIT (Sharpness, Lighting, Exposure)
   ↓ 
COLOUR CALIBRATION (Affine Normalization to CIE D65)
   ↓ 
REACTION REGION (ROI Spectral Extraction)
   ↓ 
COLOUR ANALYSIS (Matrix Distance Matching)
   ↓ 
PRESUMPTIVE RESULT (Positive / Negative / Inconclusive)
   ↓ 
EVIDENCE RELIABILITY SCORE (0 - 100 Multi-Parameter Synthesis)
   ↓ 
EXPLAINABILITY ("Why This Result?" Full Traceability)
   ↓ 
RESULT STABILITY (Robustness & Perturbation Tolerance)
   ↓ 
MANUAL SUPERVISORY REVIEW RECOMMENDATION
   ↓ 
DIGITAL EVIDENCE RECORD (4-Tier SHA-256 Custody Seal)
   ↓ 
INTEGRITY VERIFICATION (Cryptographic Chain Audit)
```

## 4. Architectural Stack & Portability

- **Client Runtime:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Clean Paper & Elevated Card Shadows
- **Hero Visual:** 2D/3D Hybrid Scientific Evidence Visualizer (`ScientificEvidenceVisual.tsx`) with 6-patch card inspection, reaction well meniscus, and optical coincidence markers.
- **Cryptographic Engine:** Web Cryptography API SHA-256 (Ed25519-compatible digest chain)
- **Colorimetric Calibration:** 6-Patch CIE $\Delta E$ Euclidean approximation & $3 \times 3$ Affine Normalization Matrix
- **Database Schema:** Standard SQLite 3.38+ / PostgreSQL relational schema (`operators`, `tests`, `evidence_images`, `analysis_results`, `reliability_assessments`, `robustness_results`, `evidence_records`, `test_kit_profiles`)
